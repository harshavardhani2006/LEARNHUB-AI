---

## About LearnHub AI

**LearnHub AI** is a collaborative educational resource sharing platform with an integrated RAG (Retrieval-Augmented Generation) learning assistant. Students and educators can upload, browse, and learn from study materials while an AI tutor provides contextual explanations, summaries, revision notes, and educational diagrams.
